# Preserved Abyssals source files

Original artwork, trainer-code sheets, character rosters, source packs and historical files imported from the Abyssals Library folder on 20 October 2026. The migration index records original filenames, source identities, dates, byte sizes and SHA-256 checksums. Large files are stored as numbered parts for exact reconstruction using the accompanying restore script.

These are historical/reference sources, not live game assets. Original names and embedded historical instructions do not supersede the current project protocol or canonical names. Pate is CHR-PATE (Peter “Pate” FitzRobert); Trade is CHR-TRADE (Thomas “Trade” de Clare). Use reviewed transparent portraits from art-library/characters/ready when integrating future story scenes. Avoid Poké Balls in production artwork.

Library removal is permitted only for an original whose complete byte-identical content has been verified against the committed archive. Do not delete on upload success alone.
