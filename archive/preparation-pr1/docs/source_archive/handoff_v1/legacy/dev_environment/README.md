# Prior development-environment work

The project previously created Steam Deck setup packages v1–v3. The active coding handoff does not need those scripts to build the game, but their workflow is preserved here. The latest design used Ubuntu 24.04 in Distrobox, Node 22, Git/Python, Codex, Claude Code, optional OpenRouter/Ori, optional local OmniRoute, Open Generative AI, Pillow/ImageMagick/FFmpeg, and strict generated-vs-production asset separation.

Use `tools/deck_dev_bootstrap.sh` as the concise handoff replacement. The original `Abyssals_Deck_Setup_v3.sh` remains listed in the source inventory for archival import.
