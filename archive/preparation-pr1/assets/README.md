# Asset ownership and missing production categories
Source originals are immutable and checksummed. Runtime files must resolve through manifests and pass framing/transparency/identity checks. No back sprites are required. Do not redraw or generate substitutes.

Overworld sprites, environment/map art, UI, VFX (including 18 execution proxies), and audio are separate future production passes; no files were supplied for them. Create those folders only when a real asset or specific contract exists. Source art is not bulk-pre-cached in the PWA.
