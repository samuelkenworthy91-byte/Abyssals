# Pale Gate source art

Generated with built-in image generation and prepared as WebP. The six environment briefs shared a 3:2 orthographic 32-bit RPG viewpoint, clean snow clusters, blue spruce, blue shadows, amber lights and a largely clear playable strip in the middle-lower third.

| Source | Brief |
| --- | --- |
| quay | Winter river arrival quay, pale cobbles, open square, low shelters, south branch. |
| river | Vertical blue river with open left and right banks, birches and rippling current. |
| hall | Open-air limestone archive with a broad flagstone court and amber-lit niches. |
| prince | Pale winter audience terrace with distant mountains and a stone arch. |
| orchard | Snowy birch orchard, clear horizontal path, low wall and warm winter sun. |
| reeds | Frosted willows, a glassy pool, reeds and a broad walkable shelf. |
| actors | Worn blue soldier with bandaged arm, red-scarf soldier, subdued horned Bailiff, pale-robed Keeper. |
| hound | Hooded slate-gray humanoid hound in a dark blue winter coat. |
| props | Tablet, bell, feeding bowl, lantern buoy, ferry, flood marker, arch. |
| vantis-walk | Grey-templed archivist in a charcoal coat with teal lining, four directions and three steps per direction. |

Runtime maps are 768×512. Character field cells are 32×48. The Vantis atlas row order is down, left, right, up, with the middle frame resting. Props and character art were cropped to their alpha and reviewed at runtime scale.
