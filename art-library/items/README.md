Inventory art created with the built-in image-generation tool for the bag icons and Grand Exchange lift patch. Both transparent source atlases are preserved here. Runtime WebP sprites are cropped per grid cell, alpha-trimmed, fitted with padding and optimized losslessly. Existing specialist food and medicine images are reused unchanged. Codex, type-sigil and relic-core families share a master sprite tinted by type, with matching type-colour underlines.
