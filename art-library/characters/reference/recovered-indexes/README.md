# Recovered historical character indexes

Exact index files extracted from the recovered standalone portrait pack, so old character codes can be searched without rebuilding the large ZIP. They describe historical source material; current game canon and the curated character catalogue take precedence. Pate is Peter “Pate” FitzRobert, and Trade is Thomas “Trade” de Clare. The old names remain in these source indexes for traceability.

These reference files are outside `dist/` and are excluded from the APK.
