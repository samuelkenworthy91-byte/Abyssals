# Marasen streets and Exchange — v0.90.12

The four existing city screens are the main overworld layer. District links are now open-air streets at screen edges, without freestanding portal arches. Lower Cascades connects north to Highwater, south to Seven Bridges and southeast along the waterfront to the Rapids; Seven Bridges also connects east to Highwater. Return streets and progress directions match. Each rendered facade has exactly one real threshold, a clear outside doorstep and an opening rendered at its collision/interaction tile. The former hidden Seed Exchange is a visible building in Seven Bridges. The Rapids Arena opens a race hall; its current outdoor services remain usable. The Exchange, apothecary, archive, mill and civic fort retain their services and prerequisites.

The six Exchange floors use individual transparent pre-rendered 3D-style sprites: potion cabinets, colourful codex bookcases, armour cases, a service counter and marble stairs. These are raster game props, not runtime 3D meshes. Stock themes vary by floor. Original room artwork supplies only a narrow architectural frieze above the playable floor; no painted background cabinets obstruct movement. Furniture rectangles are the same data for rendering and collision. Stair rear walls/balustrades are blocked; central treads, landing interaction and approaches are clear. The broad central aisle remains open. Displays are positioned for the portrait camera.

`art-library/marasen-store/source/` preserves generated PNGs outside the APK. `assets.json` records hashes and selected runtime sizes. `prompts.json` preserves the exact built-in ImageGen prompts. `scripts/prepare-marasen-art.py` reproduces the selected WebP sprites/friezes using Pillow. Eleven optimized runtime images add approximately 250 KiB. No source atlas, historical build or full reference archive is copied to dist.

The Story Bible's CH06 scenes/state contracts and current Botrune overlay were consulted. This is a geometry/art change: it does not complete, reset, rename or reinterpret any story event. Existing room IDs, quest fields, battle/encounter rules and permanent losses remain intact. Older interior saves exit through the building's current facade. Existing collision recovery safely relocates saves inside new furniture/stair rails without resetting expedition state. The canal caravan and Walter recovery fixes remain in place.

Verification includes all previous geometry/guidance tests; `marasen-store.test.mjs` enforces facade/door uniqueness and absence of floating entrances, screen-edge streets, six-floor stair collision and clear approaches. Extended `marasen-browser.cjs` uses actual Chromium movement and A interactions for counters, stair round trips, six building entry/exits, eight district street transitions, old-furniture save/reload recovery, the caravan, Emergency Evac and Journal. Screenshots are retained for each Exchange floor and exterior entrances. Existing farm, tablet and Botrune regressions remain enabled. Release 0.90.12 / Android 107 uses android-release.yml, the preserved package and original signing key. No physical-phone installation or runtime 3D import is claimed.
