# Abyssals development context

**Abyssals** is an original, story-led monster-capture RPG with a Crusade-route mortal world followed by a descent through nine Circles of Hell. It deliberately combines readable classic monster-RPG structure with irreversible Ironman state, individual moral choices and a strong authored narrative.

## Vocabulary
- **Abyssal**: capture/battle creature.
- **Aimon**: renamable protagonist.
- **Pate / Trade**: Pateric “Pate” Vann and Traden “Trade” Cor, core companions/rivals.
- **True Light / Dawn Bloom**: rival human faith/faction traditions.
- **Leader fate**: one of `UNRESOLVED`, `SPARED`, `EXECUTED` for the eight mortal leaders.
- **Permanent death**: ordinary Abyssal death at 0 HP, except non-final starter life losses.
- **Starter life**: special three-life state held only by the three original starter individuals.
- **Irreversible transaction**: state that must survive crash/reload without reroll or rollback.
- **PALE / DARK**: Hell/reordered-underworld equivalents to mortal-world DAY / NIGHT.
