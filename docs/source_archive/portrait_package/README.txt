ABYSSALS PORTRAIT PACKAGE
Created: 2026-09-02

PURPOSE
Standalone full-body character portraits gathered from this chat's currently accessible files, renamed with character/trainer/warden IDs and names.

COUNTS
- 91 standalone image files included.
- 78 canonical current portrait targets represented from the 100-target manifest.
- 1 Severin King Below variant.
- 5 alternate versions of current targets.
- 7 superseded legacy C03 identity portraits retained in a separate folder.
- 22 targets from the 100-target queue are not represented by a canonical standalone file in the current sandbox.
- Collages, grids and analysis/contact sheets were deliberately excluded.

FOLDERS
canonical/core/
  Core story portraits. CORE-xxx is a packaging/order label based on the portrait manifest queue; it is not an in-game trainer ID.

canonical/trainers/
  Current trainer portraits named ID__Name.

canonical/wardens/
  The eight uploaded Hell Warden portraits, named WRD-01 through WRD-08.

variants_and_alternates/
  Alternate/reference images and the Severin King Below variant.

superseded_legacy/
  Earlier C03 portraits whose identities were later superseded. They are preserved rather than silently discarded.

documentation/
  CONTENTS.csv — every included file and its source mapping.
  TARGET_STATUS_100.csv — status against the 100-target portrait queue.
  MISSING_FROM_CURRENT_STANDALONE_SET.txt — targets not currently represented.
  EXCLUDED_NON_STANDALONE_FILES.txt — collages/contact sheets intentionally left out.

NOTES
- Original image bytes and formats were preserved; images were not resized, recompressed, background-stripped or otherwise edited.
- The newly supplied Beric and all eight supplied Warden images are included.
- Champion Daven is marked missing because its generation hit the image-generation limit and no standalone Daven file exists here.
