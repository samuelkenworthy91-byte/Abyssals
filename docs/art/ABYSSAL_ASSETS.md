# Abyssal source art
The 89 supplied WebPs are all 1448×1086 RGB and remain byte-for-byte unchanged. Each source filename is the first/featured label on a sheet; many sheets contain several evolution-stage figures, arrows, names and type labels on white. Seventeen reviewed sheets have one figure; the remaining 72 contain multiple figures. Counting files does not establish coverage of 187 unique canonical species.

data/manifests/abyssal_art.json inventories every source, dimensions, format and SHA-256. species_id and canonical_name remain null because the handoff contains no Dex register. The observed figure count per sheet is a visual audit aid only, not a species/evolution dataset. No runtime filename is issued before identity verification and framing review.

Import the canonical 187-ID register first. Then match each labelled figure, record source bounds and provenance, and prefer existing individual source cutouts over extraction from compressed sheets. Verify all 187 IDs exactly once in the production manifest; count alternate/form art separately. Do not erase white details, redraw, stretch or fabricate sprites. No player/back sprites are required.
