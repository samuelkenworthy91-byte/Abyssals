## Implementation contract and remaining boundary

Each DAY/NIGHT state lasts ten real-time minutes. Hell/Reordered Underworld uses PALE/DARK with equivalent mechanics. Select and persist the phase at encounter creation. There are 144 separate authored tables. No complete NPC daily schedules are required. Suspended/offline/pause clock handling is not specified by the source; the exact lifecycle policy is listed as world.phase_clock_lifecycle rather than silently assuming catch-up.
