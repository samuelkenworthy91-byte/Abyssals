# v0.90.51 — Original move graphics, batch 01

Twelve dedicated 4×4 sprite sheets have been authored as indexed-palette, alpha-transparent PNG, 768×768 total dimensions with sixteen independent 192×192 pixel frames. The battle renderer uses them as move-specific effects without changing the underlying move rules, existing Mercy assets, or visual size.

Each move has an individually specified physical action and own sheet; see `art-library/action-vfx/batch-01.json`.

## Coverage
- Before batch 01: 63 protected original action sheets, six of them corresponding to the 354 base catalogue IDs.
- Batch 01: 12 previously uncovered catalogue moves, across Normal, Fire, Water, Electric, Grass, Ice, Rock and Fairy.
- After batch 01: 75 dedicated sheets total, 18 covering canonical catalogue IDs; **336 base catalogue moves still lack dedicated sheets**. Additional runtime move IDs outside the base catalogue require separate coverage analysis.
- These images are first-pass assets, not final artistic sign-off. Do not merge the branch or make v0.90.51 release-ready until pixel-detail review, motion pacing and phone screenshots pass.

## Test gates
The new audit checks dimensions, transparency, distinct frames and file uniqueness. Runtime tests verify stable IDs, loading and gameplay. Live-browser screenshots and all eight leader matches must still pass. Original protected raster hashes remain unchanged.

## Next review priorities
Refine the level of internal sprite detail, multi-frame contact choreography, movement arcs and anatomical/material clarity; in particular, the first-pass **Jaffa Breaker** and **Oathkeeper’s Edge** silhouettes are too simple for final art sign-off. Preserve action-specific identity over generic type splashes.
