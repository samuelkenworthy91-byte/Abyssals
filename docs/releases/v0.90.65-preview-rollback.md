# Abyssals v0.90.65 branch preview and signed rollback (v0.90.66)
The tested branch preview uses Android versionCode 160; rollback uses 161. Main and the published PWA remain unchanged.
Before installing: in your current Android game use Export Save, keep an external JSON backup, and never uninstall Abyssals to downgrade.
Breeding eligibility is unchanged: BOTH parents MUST share a type. Spindle is only selectable if parents are different SPECIES (species IDs differ), whether or not their evolution roots coincide. It merges the maximum ORIGINAL Prodigy bonus for each eligible stat; each stat is rolled once. Without Charm: 46.4158883% per stat, exactly 1% for six. With reusable Heirloom Charm: 53.2399571% per stat, about 2.2773% for six. Feed and Thread are exclusive alternative consumables.
A failed incompatible or same-species Spindle pairing cannot consume stock or funds. Already-created eggs retain their original rolls and recorded effects. The optional rollback APK uses v0.90.62 gameplay with original signing certificate and versionCode 161; it retains preview-only Spindle stock as inert records and accepts all committed preview eggs (including stacked Charm) for later hatching. Download rollback only if rejecting the preview.
The PWA is a ZIP requiring separate hosting; do not deploy this preview over the live Pages origin.
