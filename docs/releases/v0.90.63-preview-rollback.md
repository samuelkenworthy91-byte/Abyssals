# v0.90.63 isolated preview and save-safe rollback

Source baseline: published v0.90.62, Android versionCode 157, commit a2085fd47914b538ace9ae8693900fd62de0b65f. Preview branch: feature/v0.90.63-citadel-interior-confluence-sort, Android versionCode 158.

## Before installing on the current phone

1. Open the current v0.90.62 game and use its Export Save function. Verify that the downloaded Abyssals JSON file is nonempty and retained somewhere outside the app (ideally a second copy).
2. Do **not** uninstall Abyssals or clear its app data. Installing a verified APK signed with the existing release certificate and higher versionCode should update the same package and retain the current saves.
3. This branch remains separate from main. Only test the preview APK after the signing certificate matches SHA-256 6dafd2bf38549cb39acd54811ee21cf71eb9af37a115154a5c551fc85edc92ac.
4. An independently hosted branch PWA will not automatically share browser/WebView storage with the published PWA. Import the exported JSON there; do not deploy the preview bundle over the live Pages origin.

## If rejected

- Revert the feature-branch commits (no main changes exist); do not delete the saved-game slot or reinstall an older Android APK in place.
- Android prevents a v0.90.62 APK (versionCode 157) from replacing preview 158 without uninstalling and losing app data. Publish a **forward rollback** signed with the same keystore and package ID, versionCode at least **159**, containing the v0.90.62 gameplay with narrow save-compatibility support for preview-only nursery state.
- A preview-used save may contain `state.nurseryItems.confluenceSpindle` and eggs with `breedingEffects.enhancer='spindle'`. A bare v0.90.62 runtime would reject them. The rollback must keep an inert, validator-recognised item ID and accepted egg effect, or migrate these records transactionally without deleting eggs, before any such save can be loaded.
- Original Prodigy inheritance records remain v2, so hatched descendants can retain earned growth when reverting. Never reroll existing eggs, overwrite party/reserve or erase deaths/quests.
- Always retain the pre-preview JSON export as the guaranteed restore point; import it into the forward-rollback build if continuing from the original exact state is preferred over retaining preview progress.
- Do not offer the downgrade APK as a safe rollback route. A separate, version-incremented rollback build must pass save migration, original-signature and installation checks before delivery.
